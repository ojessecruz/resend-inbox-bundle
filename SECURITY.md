# Security Policy

Please **do not** open a public issue for a security problem.

Report it privately through [GitHub's private vulnerability reporting](https://github.com/ojessecruz/resend-inbox-bundle/security/advisories/new). Include the affected version, a description of the problem and, if possible, the steps to reproduce it.

You will get an answer within 7 days. Fixes are released for the latest minor version only.
